# 使用说明

## 1. 环境准备

1.1 Windows 10/11，已在 BIOS 开启硬件虚拟化（VT-x / AMD-V）并启用 Hyper-V 或虚拟机平台


1.2 Android SDK（emulator、platform-tools，建议含 cmdline-tools 与 build-tools）与 Java 17+


1.3 在"设置 → SDK"中确认 Android SDK 与 Java 路径已自动探测或手动选择；HarmonyOS SDK 可探测本机 DevEco Studio，也可在应用内登录华为开发者账号后直接下载

## 2. 项目与设备池

2.1 **项目驱动模式**：点击"新建项目"创建项目。每个项目拥有独立的虚拟机、应用库与测试记录，互不干扰


2.2 **设备池模式**：设备池中的设备为所有项目共享，适合常用机型


2.3 侧栏"项目 / 设备池"可下拉展开设备列表，点击设备名进入设备详情

## 3. 新建与启动虚拟机

3.1 在项目页或设备池点击"新建虚拟机"


3.2 依次选择设备类型 → 机型，系统大版本 → 具体镜像（均为级联选择，需先装好对应系统镜像）


3.3 高级配置（内存 / CPU 核数 / 数据分区）留空即使用推荐值


3.4 点击"启动"，等待状态变为"运行中"；模拟器窗口可自由拖动，不会被拉回，启动尺寸不超过屏幕的 75%


3.5 启动后屏幕右侧出现药丸操作条：电源、音量 +/-、截图、旋转、返回、桌面、多任务，可整体拖动

## 4. 应用测试

4.1 在设备详情"测试的应用"导入 APK：设备运行中时**导入即自动安装**


4.2 设备从停止到启动完成后，会**自动补装库中全部应用**


4.3 安装失败会在右上角弹窗提示具体原因


4.4 "更新"按钮可对运行中设备重新安装指定应用


4.5 测试记录（结果 / 截图 / logcat）在设备详情下方按作用域归档

## 5. SDK 与下载管理

5.1 "设置 → SDK"内切换 Android / HarmonyOS 管理组件：已安装、可安装、搜索、安装 / 卸载；HarmonyOS 组件支持登录华为开发者账号后在应用内直接下载（登录在华为官方页面完成，账号凭据仅保存在本机）


5.2 "网络与下载"中分别为 Android 与 HarmonyOS 选择下载线路：展开自动测速（延时 / 下载速度 / 丢包率），点击线路左侧圆点选择


5.3 "下载管理"页实时显示下载进度、速度与剩余时间，支持取消、限速与并行数配置

## 6. 相机画面来源

6.1 "设置 → 模拟器"的相机画面来源决定虚拟机内应用调用相机时看到的画面：软件仿真（默认）/ 识别 Windows 屏幕（适合扫码）/ 调用 Windows 摄像头


6.2 选择"调用 Windows 摄像头"时可指定摄像头设备；配合 OBS 等虚拟摄像头把屏幕采集为摄像头源，即可实时投屏


6.3 修改后下次启动虚拟机生效；相关画面仅在本机与虚拟机之间流转，开发者不经手也不存储

## 7. 存储与维护

7.1 "设置 → 存储"列出设置文件、应用日志、下载记录、Agent 接入脚本、虚拟机与应用库等位置，可一键打开


7.2 支持一键清理全部虚拟机（含所有项目）、清理应用日志；"恢复初始状态"会清空全部项目、设备池数据、下载记录、日志与设置，操作前请备份重要数据

## 8. Agent 接入

8.1 "设置 → Agent 接入"启用控制桥后，ZCode、Codex CLI 等本机 AI 工具可经 MCP 直接操作在线虚拟设备：截图、点击、滑动、输入文字、shell、读取界面控件树


8.2 复制页面上的 mcpServers 配置片段加入 AI 客户端（需本机已安装 Node.js）；服务仅监听本机，令牌请勿外泄


8.3 对话中直接描述目标即可，例如"在 Pixel_Test 上打开设置并截图确认版本号"

## 9. 常见问题

9.1 **模拟器窗口黑屏**：在"设置 → 模拟器"切换图形后端（默认软件渲染兼容性最好）


9.2 **SDK 就绪但无法创建虚拟机**：确认已安装对应系统镜像（"可安装"列表中安装）


9.3 **HarmonyOS 显示未检测到**：安装 DevEco Studio、在设置中手动选择 SDK 目录，或在 SDK 页登录华为开发者账号直接下载


9.4 **虚拟机内相机无画面**：确认"设置 → 模拟器"的相机来源与摄像头设备选择；"识别 Windows 屏幕"模式取打开相机那一刻的屏幕画面
