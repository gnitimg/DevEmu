# 使用说明

## 1. 环境准备

- Windows 10/11，已在 BIOS 开启硬件虚拟化（VT-x / AMD-V）并启用 Hyper-V 或虚拟机平台
- Android SDK（emulator、platform-tools，建议含 cmdline-tools 与 build-tools）与 Java 17+
- 在"设置 → SDK"中确认 Android SDK 与 Java 路径已自动探测或手动选择；HarmonyOS SDK 路径同理（需 DevEco Studio 安装）

## 2. 项目与设备池

- **项目驱动模式**：点击"新建项目"创建项目。每个项目拥有独立的虚拟机、应用库与测试记录，互不干扰
- **设备池模式**：设备池中的设备为所有项目共享，适合常用机型
- 侧栏"项目 / 设备池"可下拉展开设备列表，点击设备名进入设备详情

## 3. 新建与启动虚拟机

1. 在项目页或设备池点击"新建虚拟机"
2. 依次选择设备类型 → 机型，系统大版本 → 具体镜像（均为级联选择，需先装好对应系统镜像）
3. 高级配置（内存 / CPU 核数 / 数据分区）留空即使用推荐值
4. 点击"启动"，等待状态变为"运行中"；模拟器窗口可自由拖动，不会被拉回

## 4. 应用测试

- 在设备详情"测试的应用"导入 APK：设备运行中时**导入即自动安装**
- 设备从停止到启动完成后，会**自动补装库中全部应用**
- 安装失败会在右上角弹窗提示具体原因
- "更新"按钮可对运行中设备重新安装指定应用
- 测试记录（结果 / 截图 / logcat）在设备详情下方按作用域归档

## 5. SDK 与下载管理

- "设置 → SDK"内切换 Android / HarmonyOS 管理组件：已安装、可安装、搜索、安装 / 卸载
- "网络与代理"中分别为 Android 与 HarmonyOS 选择下载线路：展开自动测速（延时 / 下载速度 / 丢包率），点击线路左侧圆点选择
- "下载管理"页实时显示下载进度、速度与剩余时间，支持取消、限速与并行数配置

## 6. 常见问题

- **模拟器窗口黑屏**：在"设置 → 模拟器"切换图形后端（默认软件渲染兼容性最好）
- **SDK 就绪但无法创建虚拟机**：确认已安装对应系统镜像（"可安装"列表中安装）
- **HarmonyOS 显示未检测到**：安装 DevEco Studio，或在设置中手动选择 SDK 目录
