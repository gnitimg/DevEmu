# 更新记录

## v1.1.6

- 修复应用内更新“点了安装却没反应”：安装器被杀软/ACL 拦截时（spawn EACCES）失败被静默吞掉，应用照常退出且版本不变——现在失败自动降级系统 Shell 启动；仍失败则应用保活、提示安装包路径并打开所在目录
- 静默升级等待旧实例退出的时间 2s→3.5s，消除覆盖文件时的退出竞态

## v1.1.5

- 修复：数据迁移/数据根切换时主进程被同步复制阻塞，整窗“未响应”——迁移改为异步执行，跨盘搬迁期间界面全程可响应，进度圆环实时推进
- 数据根目录“浏览”与“迁移数据”统一走同一条迁移管线（目标 `<目录>\.data`、目标非空时三选、断开设备、完成后提示重启）

## v1.1.4

- 下载断点续传：网络瞬断（ECONNRESET / 超时）自动重试最多 3 次，从已收字节处继续下载不再重头；服务端不支持断点时自动重下
- 更新包下载失败不再重复弹两个提示（由更新弹窗统一承接，消息带“更新包下载失败”语境）
- 侧栏下载胶囊与下载管理进度条同源取值，消除两条进度不一致；下载完成时进度条以 0.5s 动画补满再归档
- 数据迁移目标统一为 `<所选目录>\.data`：不存在自动新建、非空时可选“抹掉并迁移 / 合并迁移 / 取消”；迁移过程弹窗展示圆环进度并锁定界面，完成后圆环变绿打勾并提示重启
- 数据根保存失败时表单显示回滚到已生效值，不再误导

## v1.1.3

- 存储页新增"迁移数据"：一键把项目、虚拟机、应用库等全部数据迁到指定目录，自动断开所有设备连接与控制桥，完成后提示重启
- 数据根支持迁入旧根下的 `.data` 子目录（升级新版式不再被"嵌套目录"限制挡住）；仍拦截迁入 projects/devices 内部等会导致数据分裂的目标

## v1.1.2

- 安装包换用 NSIS：首次安装可**自选安装目录**；应用内升级静默装回原目录并自动重启
- 默认数据位置改为**安装目录下的 `.data`**（settings.json、虚拟机、应用库、崩溃记录都在这里）；从旧版本升级自动沿用既有数据位置，虚拟机不搬家
- 首次安装完成打开后主动展示使用说明（含数据位置说明）
- 检查更新发现新版本改走全局弹窗与侧栏通知卡；下载进度不再重复弹窗，下载完成弹"已就绪"提示安装
- 修复：取消下载后侧栏通知卡卡在"正在下载"；下载管理按任务类型区分"卸载/删除"

## v1.1.1

- 检查更新发现新版本改走全局更新弹窗与侧栏通知卡，关于页不再内联展示更新卡片
- 侧栏通知卡改单卡轮播：卡内底部圆点指示、5 秒自动轮换（悬停暂停）、点击圆点跳转；单通知时保持静态卡片

## v1.1.0

- 应用内更新升级：更新包下载并入下载管理（进度、速度、取消与侧栏下载胶囊联动）；检查更新结果改为右上角临时弹窗，已是最新版本或仓库暂无发布版本不再常驻报错条
- 侧栏收起态重构：点分组图标改为右侧浮出项目/设备列表，不再整体展开；新增通知铃铛与通知中心，HarmonyOS SDK 提醒与新版本提醒收进通知浮层
- 崩溃记录：自动采集 Android logcat 与 HarmonyOS faultlogger 崩溃并入库，设备池直接查看最近 15 条（应用崩溃 / ANR / 系统级），替换原运行记录体系
- 设备应用管理：查看设备内应用、安装进度弹窗，启动完成后自动补装库中应用
- HarmonyOS 看齐 Android：设备池/详情/操作中心同构，镜像下载与数据分区扩容，SDK 未检测侧栏提醒与下载中心 zip 一键导入落位
- 新建虚拟机默认命名：机型 + 日期序号自动生成，机型名自动清洗为合法 AVD 名
- 稳定性：例行深度审查 8 轮共 77 项修复（qemu 输出阻塞、窗口守卫竞态、限速死锁隐患、打包链路资源缺失等）

## v1.0.0

- 应用内自动更新：启动后与定期自动检查更新（可在设置关闭），发现新版本弹窗提示，一键下载（真实进度 + sha256 完整性校验）并安装重启
- 虚拟定位与药丸控制中心：罗盘方向模型、选点即生效、窗口组随设备同生共死
- 定位体验：姿态合成竖屏带钳制（极端转弯不横翻）、定位面板收起态药丸
- 模拟器窗口（2026-11-08）：使用可用的官方设备皮肤，保留机身边框、原生屏幕圆角和透明外轮廓；移除固定比例硬裁剪，恢复当前机型的圆角安全区
- 皮肤启动修复：启动前自动补全 AVD 的 `skin.path`，让 Qt 同时加载机身轮廓和屏幕遮罩，修复灰色矩形背景与白色屏幕越过圆角；保留有效自定义皮肤，兼容 SDK 迁移后的路径查找，配置写入失败不再静默继续
- 启动回调保护：已退出或被替换实例的延迟就绪回调不再向复用端口的设备恢复旧机型装饰
- 修复：三窗拖动原生同移不再滞后；GPU 默认改回 ANGLE/Direct3D，修复 API 35+ 预览镜像全屏全黑；守卫退出竞态与孤儿窗口兜底
- 数据根切换：跨盘合并搬迁、AVD ini 路径改写、源根清空无残留
- 使用条款更新至 v1.1

## v0.1.0

- 项目驱动 / 设备池双模式，项目间虚拟机、应用与记录完全隔离
- 虚拟机全生命周期：级联新建（机型 / 系统 + 推荐硬件配置）、启动、编辑、删除、重命名
- 模拟器窗口管理：移入可见区、禁止拉伸、多开级联，用户移动后不再拉回
- 相机画面来源：设置-模拟器可选软件仿真 / 识别 Windows 屏幕（截屏作相机，适合扫码）/ 调用 Windows 摄像头

- APK 测试链路：导入解析、自动安装、启动完成自动补装库中全部应用、失败右上角弹窗
- 测试记录归档：结果、截图与 logcat 按作用域保存
- SDK 管理：Android 组件安装 / 卸载 / 搜索，镜像管理，Android / HarmonyOS 双视图同构
- 下载管理：真实速度与剩余时间、并行队列、取消、令牌桶限速
- 设置：存储 / SDK / 网络与代理（双系统下载线路测速选择）/ 下载与限速 / 模拟器 / Agent 接入 / 关于
- 关于页：使用说明、使用条款、开源协议、开发者、更新记录、检查更新（md 阅读器）
- HarmonyOS 适配启动：DevEco / SDK / hdc 环境探测、组件扫描与卸载
- Agent 接入：本机控制桥 + MCP 桥，ZCode / Codex 等 AI 工具可自主操作虚拟设备（截图 / 点击 / 滑动 / 输入 / shell / 界面树 / 启停）
